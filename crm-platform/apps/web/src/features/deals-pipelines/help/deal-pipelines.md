## What it is for

A pipeline is the ordered list of stages a deal moves through. Here you create pipelines, set their currency, edit their stages and manage the reasons offered when a deal is lost. The result is what you see on the [Deals](help:deals-overview) board.

## How to use it

1. Open **Settings**, then **Data and customization**, then **Pipelines and stages**, or go to `/deals/settings`.
2. Select a pipeline on the left to edit it. The default one is marked **Default**.
3. To add a pipeline, select **New pipeline**, enter a name and currency, and select **Create pipeline**. It starts with New, Won and Lost stages.
4. Under **Pipeline**, change the name (saved when you leave the field) or the currency. **Make default** opens the board on this pipeline.
5. Under **Stages**, rename a stage, change its colour, probability or order, or delete it.
6. Use **New stage** to add one: a name, a type and a probability.

## Options and settings

- Open stages come first, then one **Won** and one **Lost** stage. Won is always 100% and Lost 0%. Only an empty stage can change type.
- Deleting a stage or pipeline that holds deals asks where to move them. The default pipeline cannot be deleted.
- **Lost reasons** are the choices offered when a deal is lost. Add, rename, reorder, switch off or delete them.
- **Require a reason to mark a deal as lost** controls whether a reason is compulsory.

## Plan and access

Opening the screen needs permission to read pipelines. Editing needs the permission to update pipelines; without it the controls are disabled. Creating and deleting pipelines need their own permissions. Deals belong to the sales pipeline feature of your plan, which may also limit the number of pipelines.

## If something looks wrong

- **A stage still has deals.** Choose where they move to before deleting it.
- **A pipeline can have only one Won and one Lost stage.** Change the type of the other stage.
- **The default pipeline cannot be deleted.** Make another pipeline the default first.
