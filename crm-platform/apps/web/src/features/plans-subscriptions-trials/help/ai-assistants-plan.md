## What it is for

AI assistants answer customers and carry out simple steps inside a conversation, using the AI provider keys your workspace has set up.

## How to use it

1. Add an AI provider key in the AI keys section of Settings.
2. Create an assistant and choose the provider and model it uses.
3. Link the assistant to the conversation or flow where it should answer.

## Plan and access

AI assistants are available on plans that include them. Your workspace pays for the provider key's usage, so check the usage screen to keep an eye on cost.

## If something looks wrong

An assistant that stays silent usually has no provider key, no linked flow, or a key that has been disabled. Check the key, then its usage for an error.
