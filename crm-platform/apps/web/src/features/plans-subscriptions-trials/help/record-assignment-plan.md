## What it is for

Record assignment rules decide who owns a new contact, company or deal, using priority rules with conditions on the record's fields.

## How to use it

1. Open **Settings**, go to **Automation** and select **Record assignment rules**.
2. Switch it on, then create a rule for contacts, companies or deals.
3. Order the rules by priority, since the first match wins.

## Plan and access

Record assignment rules are included in plans that list them. On a plan without them, the screen is locked. Changing rules needs the permission to manage record assignment.

## If something looks wrong

A record that goes to the wrong person usually matches a rule with a higher priority. Check the order of the rules and their conditions, and use the test box on the screen.
