## What it is for

WhatsApp calling lets your team place and receive voice calls with customers on a connected WhatsApp number, from the inbox.

## How to use it

1. Connect a WhatsApp number that supports calling.
2. Turn on calling for that number in the calling settings.
3. Use the call controls in the conversation to place or answer a call.

## Plan and access

Calling is included in plans that list WhatsApp calling. On a plan without it, the calling settings are locked. The number must also support calling at the provider.

> Leaving the calling screens ends a live call, so finish the call first.

## If something looks wrong

A call that will not start usually means calling is off for the number, or the number is not set up for calling. Check its calling setting, then its connection status.
