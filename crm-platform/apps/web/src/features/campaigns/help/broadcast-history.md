## What it is for

Every broadcast you make shows up on one of three pages, depending on how you sent it, so you can find it again without searching one long list.

## How to use it

1. **Broadcast history** lists every broadcast that has run or is running, newest first. The **Type** column tells you how it went out: **Broadcast now**, **Scheduled**, or **Recurring run** (one run of a recurring broadcast). Use the filters for type, status, a date range or a name. Select a row to open its page.
2. **Scheduled broadcasts** lists the broadcasts waiting for their time, soonest first, with the time in your workspace time zone and how long is left. Select **Cancel broadcast** to stop one before it starts.
3. **Recurring broadcasts** lists the recurring broadcasts with the rule in words, the next run, the last run and how many runs have started. **Pause**, **Resume** or **Cancel series** from the row, and **Show runs** to see each run with its status and counts.

When you launch from **Create broadcast**, you land on the page that matches how you sent it, with the new broadcast marked **New**.

## Options and settings

- You need permission to view campaigns to see these pages, and permission to control campaigns to cancel, pause or resume.
- Times on these pages use the time zone set for your workspace.
- Campaigns made in the classic builder that have already started also appear in **Broadcast history**.

## Troubleshooting

- A broadcast you just scheduled is not on page one of **Scheduled broadcasts**: the list is ordered by time, so a broadcast further away is on a later page. Use the search box.
- **Cancel series** stops future runs and any run that is still waiting or sending. Messages already sent are not affected.
