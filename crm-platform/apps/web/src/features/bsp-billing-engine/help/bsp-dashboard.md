## What it is for

Every billed message is a wallet charge. This page shows this month's totals: what customers paid (revenue), what Meta bills you (cost), and the gap between them (margin).

## Reading it

- The summary cards give revenue, Meta cost and margin for the month, in the base currency set on the [Meta credit page](help:bsp-credit).
- The tables break the same figures down by country and message category.
- A banner appears when some billed messages have no Meta cost set for their country and category. Those messages count as pure revenue, so the margin looks higher than it is.

## Fixing missing costs

Use the **Rates & margin** link to open Wallet rules, then sync or add the Meta cost rows. The figures update on the next load.

## If something looks wrong

If the page says it could not load, choose **Try again**. A currency selector in the header changes how amounts are shown, not what was charged.
