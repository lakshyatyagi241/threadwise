## What it is for

The roster lists the operators who can be assigned tickets. Active agents appear in the ticket **Assign to** list.

## How to use it

1. Open **Support**, then **Agents**. The tiles show **Total agents**, **Active**, **Open tickets** and **Unassigned**.
2. To add one, choose an operator under **Operator**, optionally type a **Specialty** such as billing, and select **Add agent**.
3. The **Agent roster** shows each agent's open tickets, tickets resolved in 30 days and average first reply.
4. Use the **Active** switch to turn an agent on or off, and **Remove** to take them off the roster.

> Only active platform operators can be added or assigned tickets.
