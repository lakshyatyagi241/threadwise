## What it is for

A playbook bundles up to three actions you would otherwise do one by one: set status, set priority, add tag, send reply, assign agent, add internal note.

## How to use it

1. Open **Support**, then **Playbooks**. The tiles show **Total**, **Active** and **Runs (all-time)**.
2. Under **New playbook**, enter a **Name**, choose a **Trigger** and fill up to three steps. Empty rows are ignored. Select **Create playbook**.
3. Use **Pause** or **Activate** to switch a playbook, and **Delete** to remove it.
4. Run one from a ticket: in the [Support inbox](help:support-operator-inbox) panel choose it under **Run playbook** and select **Run**. Only active playbooks can run.

> Playbooks run when you choose them. The trigger field is stored, but nothing fires a playbook automatically.
