## What it is for

Order history lists everything your workspace has bought from the platform: plan purchases and wallet top-ups. Each row shows the order number, what was bought, the date, the amount, its status and a link to the invoice. The total you have spent so far is shown above the list.

## How to use it

1. Open **Settings**, go to the **Business and billing** section and select **Order history**.
2. Read the status of each order: **Pending**, **Awaiting approval**, **Paid**, **Failed**, **Cancelled** or **Refunded**. A failed order shows the reason the provider gave.
3. To see the invoice of an order, select **Invoice**. It opens on its own page, where **Print** prints it.
4. If an order is still pending and you paid by bank transfer or another offline method, select **Payment proof** on that row. Choose a receipt (JPG, PNG, WEBP or PDF, up to 4 MB), add the payment reference if you have one, and submit.
5. Select **Load more** at the bottom to see older orders, 25 at a time.

> Right after a payment, this page shows whether it succeeded, failed, was cancelled or is still waiting for the provider. The page does not refresh by itself, so reload it to see the latest status.

## Options and settings

This page has no settings. The only action is the payment proof upload on pending offline orders.

## Plan and access

Opening the page needs the permission to view the workspace order history. Uploading a payment proof also needs the permission to buy a plan, add-on or wallet top-up. By default only the Owner role holds these permissions, so other roles see the Settings tile only after an Owner grants them.

## If something looks wrong

- **The order you expect is missing.** Only orders bought for this workspace are listed. Reload the page first. If it still does not appear, write to support from the Support page with the time and the amount.
- **The proof form says the order is closed.** Proof can only be added while the order is still pending. Contact support if the payment was made and the order is not yet paid.
- **You cannot open the page.** Your role does not include the order history permission. Ask a workspace Owner.
