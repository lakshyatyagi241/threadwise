## What it is for

The Instagram broadcast sends one message to people who have already messaged your linked Instagram account. Instagram lets an account message only people who wrote to it first, so the list offers existing conversations only. Instagram applies its 24-hour window when each message is sent.

## How to use it

1. Open **Instagram broadcast** in the menu. If no account is linked yet, the screen says so and links to the accounts page.
2. Enter a **Broadcast name**. This name is for your records.
3. If you have more than one account, choose the **Instagram account** to send from.
4. Optionally pick a **Template**. It fills the message only while the message box is empty.
5. Write the **Message**. Use `{name}` where the person's name should go. The message can be up to 1000 characters.
6. On the right, tick the conversations to reach. Use the search box to find one, or **Select all** to pick the first 200 shown.
7. Select **Send to** the number of conversations. The result shows how many were delivered and how many failed.

## Options and settings

- Each conversation shows **In window** when its 24-hour window is open, or **Outside 24h** when it is closed. Outside the window, Instagram may refuse the message.
- **Clear** removes the selection.
- One send reaches at most 200 conversations. Send again for the rest.

## Plan and access

You need the Instagram broadcast permission to open this screen. The account itself must be linked on the [Instagram accounts](help:instagram-accounts) page. Your plan must include the Instagram channel.

## If something looks wrong

- **"No Instagram account is linked and connected yet."** Link an account first.
- **Send stays off.** Enter a name and a message, and tick at least one conversation.
- **"Could not send to any recipient."** Check that the account still shows as connected on its accounts page.
- **The list is empty.** Nobody has messaged the account yet. People appear here after they message it.
- **Some messages failed.** Those conversations were outside the window or could not be reached. Try again later.
