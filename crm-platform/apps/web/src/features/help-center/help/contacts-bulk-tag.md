## What it is for

Tags are labels you can use to find people and to pick an audience for a send. Instead of tagging contacts one by one, you can find them with a search or a filter, select all the matches, and tag them together. For the whole screen, see [Contacts](help:contacts-overview).

## Tag everyone a search finds

1. Open **Contacts**.
2. Narrow the list. Type a name or number in the search box (Ctrl K jumps to it), or use **Select Segment**, **Select Tag** and **Filters** for stage, opted-in or opted-out status and sort order.
3. Tick the box in the table header. It selects the contacts loaded on this page.
4. If more contacts match than fit on the page, a bar appears saying "All contacts on this page are selected". Select **Select all** with the number of matches to extend the selection to every contact matching your search and filters, on every page.
5. Open **More Actions**. Under **Selected contacts**, choose **Tag**.
6. In **Add tag**, pick a tag from the list, or type a new tag name. Typing a name that already exists reuses that tag.
7. Select **Apply**. A message tells you how many contacts were tagged.

## Remove a tag or use a group instead

- To take a tag off, choose **Untag** under **Selected contacts**, pick the tag and select **Apply**.
- To gather the same people in a list, choose **Add to group** or **Remove from group** and pick a [group](help:contact-groups). You need to create a group first if there are none.
- To check the result, use **Select Tag** to filter by that tag. The **Tags** column also shows each contact's tags, and **Modify Columns** turns it on if it is hidden.

## How the selection behaves

- With "all matching" selected, the action applies to the filter, not to a fixed list of people, and the counter reads "All matching selected".
- Unticking any row drops back to the rows you have ticked.
- A single action changes at most 50,000 contacts. If more match, the screen asks you to narrow the filter.
- To tag the members of a saved rule instead, see [Message the people in a segment](help:segment-to-audience).

## Access

Tagging, untagging and grouping need the right to update contacts. Typing a new tag name also needs the right to create tags, and tags count against a limit on your plan. If you are not allowed, those controls are hidden or disabled.

## If something looks wrong

- **Tag is greyed out.** Nothing is selected. Tick at least one row first.
- **A message says some contacts could not be updated.** The rest were updated. Select the contacts again and repeat the action.
- **The tag is not in the list.** Type its name instead, if you may create tags.
- **Too many contacts match.** Narrow the search or add a filter, then try again.
