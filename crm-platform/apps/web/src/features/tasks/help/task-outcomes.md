## What it is for

**Task outcomes** is your workspace's list of results for a task, such as **Interested**, **Left message**, **No response** or **Not able to reach**. When someone completes a task they can pick one, so the team can see how a follow-up or a call went. Everyone in the workspace shares the same list.

## How to use it

1. Open **Settings**, then **Task outcomes** in the Data and customization section. You can also open it from the gear on the **Tasks** screen.
2. To add an outcome, type its name in **New outcome** and select **Add outcome**. It goes to the end of the list. A name another outcome already has (capital letters do not matter) is refused.
3. To rename an outcome, change its name in the list and leave the box. The change is saved.
4. Use the arrows at the start of a row to move an outcome up or down. The order here is the order the pickers show.
5. Use the switch on a row to hide an outcome or show it again.
6. Select the bin to delete an outcome and confirm.

## Where outcomes show up

- On a task, the **Outcome** field in the new and edit forms and in the task panel. Choose **No outcome** to clear it.
- In a task's panel, **Complete with outcome** completes an open task and records the outcome in one step.
- In the task list, as an **Outcome** column (turn it on under **Modify columns**) and as an **Outcome** filter. These appear once the workspace has at least one outcome.

## Hiding and deleting

- A hidden outcome is no longer offered, but tasks that already have it keep it and still show it, marked as hidden.
- An outcome that tasks still carry cannot be deleted; the row shows how many tasks use it and the bin is disabled. Hide it instead.

## Plan and access

Everyone who can read tasks sees the list. Adding, renaming, hiding, reordering and deleting need the permission to manage task outcomes, which the Owner and Admin roles have. Task outcomes are available on every plan.

## If something looks wrong

- **I cannot change the list.** You need the permission to manage task outcomes. Ask an Admin.
- **The outcome picker is missing on a task.** The workspace has no outcomes yet, or none are shown. Add one here.
- **Someone else changed this outcome.** The list was reloaded. Make your change again.
