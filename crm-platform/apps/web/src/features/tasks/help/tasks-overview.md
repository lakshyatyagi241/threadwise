## What it is for

**Tasks** is your list of follow-ups and to-dos. Each task has a title, a priority (High, Medium or Low), an optional due date and time, an optional assignee, notes and an optional link to a contact or a deal. The assignee gets a reminder when the task becomes due.

## How to use it

1. Open **Tasks** in the CRM area of the menu, or go to `/tasks`. The tabs are **My tasks**, **All tasks**, **Overdue**, **Today**, **Upcoming** and **Completed**, each with a count.
2. To add a task, type in the box at the top and press Enter. It is assigned to you.
3. For more detail, select **New task** and set the priority, assignee, due date, contact, deal and notes.
4. Tick the circle at the start of a row to complete a task. On a completed task the same control reopens it.
5. Select a task to open its panel, where you can edit, add notes, complete, reopen or delete it.
6. Tick several rows to complete, assign or delete them together.
7. Narrow the list with the search box, **Priority**, **Assignee** and **Linked to**.

## Options and settings

- **Board by due date** groups open tasks into Overdue, Today, Upcoming and No date.
- **Modify columns** chooses which optional columns show. Your choice is remembered in your browser.
- Keyboard shortcuts work outside text fields: j and k move between tasks, Enter opens one, e completes or reopens it, x selects it, n starts a new task, / goes to search and ? lists all shortcuts.

## Plan and access

Opening the screen needs permission to read tasks. Creating needs the create permission, completing, editing and assigning need update, and deleting needs delete. Tasks belong to the sales pipeline feature of your plan.

## If something looks wrong

- **A task is missing.** You may be on **My tasks**, or a filter is on. Select **Clear filters**.
- **Someone else changed this task.** The list was reloaded. Try again.
- **You cannot tick or edit tasks.** That needs the permission to update tasks.
