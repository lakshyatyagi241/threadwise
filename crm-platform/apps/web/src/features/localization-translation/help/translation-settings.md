## What it is for

The Translation page holds the workspace-wide translation settings: whether automatic translation is switched on, and which language your own team reads and writes in. The page is titled **Real-time translation**. It also shows which translation engine is in use and how much has been translated this month.

## How to use it

1. Open **Settings**, then **Integrations and developer**, then **Translation**. You can also go to `/i18n/translation`.
2. Read the three steps at the top. They explain the idea: customers write in any language, your team replies in the team language, and each side reads in its own.
3. Look at the **Translation engine** card. It names the engine in use, which is the free engine unless the platform has set up another one. You do not enter any keys here, because translation is configured once for the whole platform.
4. Look at the **This month** card. It shows the characters translated and the number of messages.
5. Tick or untick **Auto-translate conversations** to turn translation on or off for this workspace.
6. Choose **Your team language**. This is the language your agents read and write in.
7. Select **Save translation settings**. The page confirms with **Translation settings saved**.

## Options and settings

- **Auto-translate conversations** is one switch for the whole workspace.
- **Your team language** is a list of languages, each shown with its name and its code. If the language already saved is not in the list, it still shows as selected.

## Plan and access

Seeing the page needs the permission to view translation settings, and saving needs the permission to change them. Translation is a plan feature. On a plan that does not include it, the page shows **Upgrade to unlock real-time translation** with a **See plans** link to [Plans](help:account-plans), and the engine card, the usage card and the form are not shown.

## If something looks wrong

- **I only see an upgrade message.** Your plan does not include translation. Upgrade the plan, or ask a workspace admin.
- **Saving says someone else changed the settings.** Another person saved at the same moment. The page reloads, so check the values and save again.
- **Saving says your plan does not include translation.** The plan changed while the page was open. Reload to see the current state.
- **The page could not load.** Reload it. If it keeps failing, your role may not have the permission to view it.
