## What it is for

A website chat bot is a bot built in the flow builder for the **Web** channel. Its chat bubble is a widget that sits on your site. This page lists every website bot with the widget it owns, so you can see which ones are live and jump to the right step. Nothing is edited here.

## How to use it

1. Open **Settings**, then **Channels**, then **Website chat**.
2. Each row shows the bot's name, the widget it runs in (or that it has none yet) and its state.
3. Select **Customize** to change the widget's look, or **Install** to copy the code that goes on your website. **Install** appears once the bot has a widget.
4. Select the bot's name to open it in the builder.
5. To make a new bot, select **New website bot**. It opens the builder for the Web channel.

## What the states mean

- **Needs customizing**: the widget has not been saved yet. Open **Customize** and save it once.
- **Draft**: the widget is saved but the bot is not published.
- **Live**: the bot is published and running, and its widget is on.
- **Paused**: the widget is paused, or the bot is switched off.

If you have more bots than the list shows, a line under it says so; open the rest from **Flows**. A visitor's chat lands in your [Team inbox](help:team-inbox-overview). The older, widget-only setup is described in [Chat widget](help:chat-widget-overview).

> You need the permission to read flows to see this page, and the permission to create flows to see **New website bot**.

## If something looks wrong

- The list does not load: refresh the page.
- A row says **Needs customizing**: open **Customize** and save the widget once.
- The bubble does not appear on your site: open **Install** and check the code is on every page where you want it.
