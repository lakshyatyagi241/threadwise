## What it is for

The **Developer** tab of the Marketplace gathers the tools for developers and technical admins in one place, apart from the apps you install, the services you connect and the packs you buy. Each tool is a card with a short description and an **Open** button that takes you to the tool's own screen.

## How to use it

1. Open **Marketplace** from the menu and select the **Developer** tab.
2. Read the card, then select **Open**. The tools are **REST API** (keys for your own software, see [REST API keys](help:rest-api-keys)), **Webhooks** (send events to your own systems, see [Webhooks](help:webhooks)), **Geta publishing** (publish a bot live from the flow builder, see [Geta publishing](help:flow-geta-publishing)) and **Translation** (see [Translation](help:translation-settings)).
3. From a tool's screen, the link at the top takes you back to the Developer tab.

## Which tools you see

You only see the tools your role may use. A tool your role may not use has no card at all, so an admin can add it to your role in **Roles**. A tool your plan does not include shows an **Upgrade** badge; open it to see which plan unlocks it. If nothing is available to you, the tab says so.

## Plan and access

The Marketplace needs a plan that includes it and the permission to see apps; without them the tab asks you to upgrade. Add-ons you buy are on the **Add-ons** tab, not here. See [Marketplace](help:marketplace-overview) and [Add-ons](help:workspace-addons).

## If something looks wrong

- **A tool is missing.** Your role does not allow it. Ask an admin to change your role in **Roles**.
- **A tool says Upgrade.** Your plan does not include it. Open the tool to see the plans that do.
- **I looked for the REST API under Add-ons.** It moved to this tab. The Add-ons tab now lists only the packs you can buy.
