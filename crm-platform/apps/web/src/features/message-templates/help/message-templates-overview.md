## What it is for

WhatsApp only lets a business start a conversation with an approved template. The Templates screen is your library: write templates, send them to Meta for review, and follow each status. Approved templates can then be used in [Broadcasts](help:broadcasts-overview) and [Campaigns](help:campaigns-overview).

## How to use it

1. Open **Templates**. Search by name, or filter by **Status**, **Category** and **WhatsApp number**. **Load more** shows older templates.
2. Select **New template**. Under **Identity**, pick the WhatsApp number to submit through, the category (Marketing, Utility or Authentication), a name using only a to z, 0 to 9 and underscores, and the language.
3. Add an optional **Header** (text, image, video, document or location), then write the **Body**. Use the formatting buttons for bold, italic, strikethrough and code, and **Add variable** to insert a placeholder.
4. Under **Variable mapping**, name the contact attribute that fills each variable when you send, and give a sample value for Meta's review.
5. Optionally add a **Footer** and **Buttons**. Meta limits each kind, and quick replies must sit together.
6. Watch the preview and **Pre-submit checks** on the right. Fix every error, then select **Save draft** to keep working later or **Submit to Meta** to start the review.

## Options and settings

- **Sync from Meta** fetches the templates already on your WhatsApp Business account.
- An **Authentication** template is a one-time passcode: Meta writes the message and the Copy code button, and you can set how long the code stays valid.
- Each template shows a status: Draft, In review, Approved, Rejected, Paused, Disabled or Missing on Meta. Approved templates also show a quality rating.
- Open a template to see its Meta details. While it is in review the page checks every 15 seconds. Only a draft, an in-review or a rejected template can be edited.

## Plan and access

You need the right to view templates to open the screen. Creating and editing, deleting and syncing each need their own right, and the matching buttons are hidden without it. You also need a connected WhatsApp number to submit through.

## If something looks wrong

- **Submit to Meta is greyed out.** A line beside the buttons says why, such as no number chosen, no name, or errors in the checks.
- **Meta refused the template.** It stays as a draft with Meta's reason. Edit it and submit again.
- **Delete is refused.** A running or scheduled broadcast still uses the template. Cancel that broadcast or pick another template first.
- **A save says someone changed the template.** Reload it and apply your change again.
