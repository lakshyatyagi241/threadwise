## What it is for

Every user has a personal referral code and link. When someone signs up through it and their workspace makes a first payment, you earn a one-time reward that is added to your wallet. The Affiliate screen shows your code, what a referral earns, who signed up and what has been paid out.

> The reward is a single fixed amount per referred workspace. It is paid once, on the first payment, and nothing further is paid when that workspace renews.

## How to use it

1. Open **Account** and select **Affiliate**.
2. Select **Copy link** and share it. A message confirms the link was copied; if your browser blocks copying, select the link under the code and copy it by hand.
3. Use **Range** to look at the last 7 days, 30 days, 90 days or all time. The figures, chart, top codes and table follow the range.
4. Read the figures at the top: referrals in the range compared with the period before it, what you have earned in total, referrals in the last 30 days, the average earned per referral, and your code with its reward.
5. In **Referrals over time**, switch between **Daily**, **Weekly** and **Monthly**. Bars are referrals and the line is credits earned.
6. Look through **Top codes** and **Recent payouts** next to the chart. Recent payouts lists up to eight rewards with how long ago they arrived and your balance afterwards.
7. In the table, type a name, an email or a code in **Search referrals**. Select **Reset** to clear the search.
8. Use **Previous** and **Next** to move through the table.
9. Select **Export CSV** to download every referral in the chosen range.

## Options and settings

- **Status**: Paid means the first payment was made and the reward was added to your wallet. Pending means the person signed up but has not paid yet.
- **Wallet transaction**: the start of the wallet entry that holds the reward, or a dash while it is pending.
- **Amounts**: shown in the platform currency, the same on every part of the screen.
- **Search**: only changes the table. The figures, chart and export always cover the whole range.

## Plan and access

Every signed-in user can open this screen. No role, permission or plan feature is needed.

## If something looks wrong

- **The programme currently pays nothing.** The platform owner has set the reward to zero. Your code and history stay available.
- **A referral is still Pending.** The reward is paid when the referred workspace makes its first payment, not when they sign up.
- **No referrals match.** Choose a longer range or select **Reset** to clear the search.
- **The data did not load.** Select **Try again**. If it keeps failing, quote the request id shown with the message to support.
- **The export failed.** Try again; the file covers the selected range only.
