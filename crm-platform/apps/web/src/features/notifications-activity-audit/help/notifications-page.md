## What it is for

The bell shows the newest notifications. **Notifications** in the menu (or **View all** in the bell) opens the full list of yours. Other people's notifications are never shown here.

## Using it

1. The numbers on top show how many are unread, how many arrived in the last day and week, and how many are kept. Select **Unread** to show only unread ones.
2. Use **All** and **Unread**, the type list and the search box to narrow the list. The search looks in the title and the text.
3. Notifications are grouped as today, yesterday, earlier this week and older. Select one to open what it is about; it is marked read.
4. **Mark all read** clears the unread number. The cross on a row removes that notification. **Clear all** removes all of yours after you confirm; this cannot be undone.
5. **Notification settings** opens where you choose which events reach you.

The list updates by itself when something new arrives or you read something on another device.
