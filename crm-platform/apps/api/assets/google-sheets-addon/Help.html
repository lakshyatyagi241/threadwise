CRM add-on help

Initial Setup

  1. In the CRM open Settings, then Google Sheets add-on, create your key and copy the Webhook URL.
  2. Here choose Initial Setup in the add-on menu and paste the Webhook URL.
  3. Pick the sheet and the trigger column (a letter such as F, or its heading in row 1). A row is sent when that cell is filled or changed.
  4. Select Send Test. Nothing is saved in the CRM; you see the columns it received.
  5. Tick Send on event (rows you edit here go straight away) and/or Send on schedule (every hour, rows changed by a form or another app), then select Submit.

Each row arrives in the CRM as a contact (an email or phone column is required) and its result is written to the CRM status column. The check shows who you are, your workspace and what your role can do; menu items your role cannot use are hidden.

Pull contacts

Writes your contacts into a sheet named CRM contacts, replacing what that sheet held. Custom properties come as attr:name columns.

Push contacts

Reads the active sheet. Row 1 holds the column names: email or phone is required; name, first name, last name, source, country code and unsubscribed are optional. Use attr:city for a custom property called city.

A blank cell never clears a stored value. Each row's result is written to the CRM status column: created, updated, unchanged or failed with the reason. Up to 500 rows go in each call.

Sync products to a shop

Reads the active sheet. Required columns: name and price. Optional: category, description, image url, sku, stock (blank means unlimited) and active (yes or no). Products are matched by SKU, then by name.

The shop is remembered in this spreadsheet, so the next sync updates the same shop.

If something goes wrong

  • Key not valid: it was replaced or revoked. Create a new one in the CRM.
  • Not installed: ask an admin to install the add-on in the CRM Marketplace.
  • Too many requests: wait the time shown and try again.
  • Request too large: send fewer rows.
