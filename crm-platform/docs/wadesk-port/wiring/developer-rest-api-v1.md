# Wiring map: developer-rest-api-v1 (API)

Read with [the inventory entry](../inventory/developer-rest-api-v1.md). `built` = in this repo and tested; `intended` = deliberately different
(reason in [parity/developer-rest-api-v1.md](../parity/developer-rest-api-v1.md)); `partial` = built, with the named gap; `blocked:<domain>` =
waits on a domain that does not exist yet.

## How a call moves

| Step             | WaDesk                                                                              | Ours                                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Get a key        | `/developers` page posts a name; one active key per workspace; raw key flashed once | `POST /v2/developer/keys` (staff, `api.keys.create`), plan limit `api_keys` decides how many; the raw key is in that answer only              |
| Authenticate     | `AuthenticateApiKey`: bearer or `X-Api-Key`, sha256 lookup, acts as the key's owner | `BearerApiKeyGuard`: prefix lookup in `db.privileged`, constant-time sha256 compare, `ctx.userId` = owner, `ctx.grants` from the key's scopes |
| Throttle         | `ApiPlanRateLimit`: plan, else platform default 600, 0 = unlimited                  | `ApiKeyAccessService.enforceRateLimit`: the same resolution (plan, platform ceiling, override -1), shared with the signed `/public/v1` guard  |
| Run the resource | `Api\V1\*Controller` calls the dashboard's controller or service                    | `resources/<group>/*.controller.ts` (thin) calls the same exported service the dashboard uses; mapper to WaDesk's snake_case shape            |
| Answer           | `{ data, meta }` / `{ error: { code, message } }`                                   | `ok()`, `pageMeta()`; every error under `/api/v1` is rewritten into `{ error }` by the problem renderer registered in the exception filter    |
| Document         | Scramble builds `/docs/api.json`; `/developers/docs` renders it                     | `ApiV1DocsService` builds the OpenAPI document from the controllers (`GET /docs/api.json`); the web page `/developers/docs` renders it        |

## Where it plugs into the rest

| Seam                       | What                                                                                                                                       | Where                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| Plans (plans)              | `api_keys` limit caps live keys; `public_api` feature locks the API; `api_rate_limit_per_minute` and the platform ceiling set the throttle | `keys/api-keys.service.ts`, `http/v1-controller.decorator.ts`        |
| Exception filter (kernel)  | `registerProblemRenderer(prefix, render)`: a surface may own its error body; this domain registers `/api/v1`                               | `common/filters/problem-exception.filter.ts` (additive, kernel seam) |
| Application start (kernel) | `main.ts` hands the live application to `ApiV1DocsService.attach` so the spec can be generated in every environment                        | `main.ts` (one line)                                                 |
| Signed partner API         | `ApiKeyGuard` keeps `/public/v1` and now reads only `kind = 'signed'` keys; both guards share `ApiKeyAccessService`                        | `public-api/`                                                        |
| Domain services (exports)  | additive exports so a key's controller can inject them: broadcasts, campaigns, scheduled, wallet query, flow runtime                       | each domain's `index.ts` and module `exports:`                       |
| Outbox                     | `api.key_created`, `api.key_revoked`; webhook delivery of contact, message, broadcast and campaign events is the integrations domain       | `keys/api-keys.service.ts`                                           |
