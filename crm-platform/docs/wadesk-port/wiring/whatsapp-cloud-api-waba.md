# Wiring map: whatsapp-cloud-api-waba (WABA)

Read with [the inventory entry](../inventory/whatsapp-cloud-api-waba.md) and [the parity doc](../parity/whatsapp-cloud-api-waba.md). `built` = in this repo
and tested; `intended` = deliberately different (reason in parity); `seam` = built here, finished by another domain that listens or binds;
`blocked` = needs code that lives in another domain's branch or does not exist yet.

## How a WhatsApp event moves

| Step                   | WaDesk                                          | Ours                                                                                                                                |
| ---------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Meta or Interakt calls | `WaWebhookController` (one big handler, inline) | `WabaWebhookController`: handshake, authentication (signature, or the platform key in the URL), then queue `waba-ingest` and answer |
| Route to a workspace   | scan every config                               | `waba_route_lookup(phone_number_id, waba_id)` (indexed), per change                                                                 |
| Work the change        | inline                                          | `WabaIngestService.dispatch` in the worker, one switch on `change.field`                                                            |
| Duplicate protection   | by message bubble (orders had none)             | Redis claim per wamid, released on failure; the inbox ledger is the authority behind it                                             |

## Where it plugs into the rest

| Seam         | What                                                                                                                                                                                                                      | Where                                                                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Inbox        | each connected number is a `whatsapp_cloud` channel made by `WabaChannelLinkService` (PR 30); the sink `WabaInboxSink` in `chat-conversations/waba-inbox-sink.ts` gained `onEcho`, `onHistory` and `onGroupMessage`       | `chat-conversations/`                                                                                                                                      |
| Inbox ingest | `NormalisedInbound` gained `group` and `history`; `InboundIngestService` keys a group thread on the group id, makes no contact for a group or history message, and backdates history with no unread and no realtime alert | `chat-conversations/inbound-ingest.service.ts`, `conversations.repository.ts` (`applyHistory`), `infra/providers/chat-conversations/channel-ingest.job.ts` |
| Contacts     | `ResolveContactInput.quiet`: no `contact.created` (no flow enrolment, no notification) and a blank name on an existing contact is filled                                                                                  | `crm/contacts/contacts.service.ts`                                                                                                                         |
| Campaigns    | `wpcampaigns.meta_clicked_count` written by the daily `WabaClickSyncScheduler`                                                                                                                                            | `waba-click-sync.service.ts`                                                                                                                               |
| Checkout     | writes `wa_orders` and `wa_order_items`; the acknowledgement, pay link and flow resume listen to `whatsapp.order.received`                                                                                                | `waba-orders.service.ts`                                                                                                                                   |
| Permissions  | `waba.numbers.read                                                                                                                                                                                                        | connect                                                                                                                                                    | manage`, `waba.customers.read | manage` (Owner, Admin) | migrations `20261014090000_waba_connections`, `20261019110000_waba_customers` |
