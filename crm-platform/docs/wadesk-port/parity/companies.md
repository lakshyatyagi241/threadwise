# Parity evidence: companies (WD-CTP-001 .. 013)

WaDesk 1.7.0 source (`CompaniesController`, `Company`, `companies/index.blade.php`, `companies/show.blade.php`, `user-companies-index.js`,
`CrmToolkit`, `routes/web.php`) against our build at branch `lakshya/contacts/contacts-port` (working tree), written 2026-10-03.
Companion files: [tasks.md](tasks.md), [deals-pipelines.md](deals-pipelines.md).

## How this was run, and its limits (read this first)

- **The Playwright twin run was NOT done.** It needs a running WaDesk reference and a running copy of our stack, and starting servers (and
  migrating the dev database) was out of bounds for this change. Nothing below was observed in a browser, on either side.
- **Reference side:** read from the licensed source only (controller, model, views, JS, migration, routes). No behaviour here was
  re-checked on the running reference, so every "WaDesk" cell is a source reading, and the inventory says so where it matters.
- **Our side:** the API is covered by 46 end-to-end tests over HTTP against a real Postgres (testcontainers) and 21 schema tests against the
  restricted application role; the web by pure-logic tests, 18 server-render tests of the components (strings, escaping, states, permissions)
  and the English/Arabic message parity test. `next dev` was not started, so layout, spacing, dark mode, RTL mirroring, 390 px, keyboard
  behaviour, focus handling of the dialogs, toasts and the navigation after create/delete are **not verified**.
- Legend: **same** = equivalent behaviour per the source and a test; **intended** = differs on purpose (a `D-nn` of
  [the inventory](../inventory/companies.md#port-decisions) or an owner extension, with the reason); **not verified** = needs the
  twin run.

## Quirks decided (inventory "Open questions & quirks")

| Quirk                                                                          | Decision                                                                                  |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 500-row cap and search after the cap                                           | Fixed (D-04): database search and cursor paging                                           |
| Tiles follow the search                                                        | Kept deliberately: the tiles take the list's filters                                      |
| Won value mixes currencies, two decimals, no currency                          | Fixed (D-06)                                                                              |
| Contacts tile capped at 200 loaded rows                                        | Fixed (D-05): exact count                                                                 |
| Dead website link (`href="#"`)                                                 | Fixed (D-08)                                                                              |
| Deal rows link to `/deals`, not to the deal                                    | Fixed (D-16)                                                                              |
| `custom_attributes` and `owner_user_id` never used; size and address not shown | Owner now settable (D-10); size and address shown; `custom_attributes` not exposed (D-18) |
| Delete leaves tasks, projects, proposals, payments dangling                    | Fixed (D-11)                                                                              |
| `GET companies/search` has no caller                                           | Kept as `select-data` (D-13); used by nothing in the web yet                              |
| Contact 360 page 500s (WD-CON-018)                                             | Not reproduced: the port's contact page works and the company's contact rows link to it   |
| No company field on the contact form or the CSV import                         | Kept: not added (the company page links contacts instead); the APIs accept `companyId`    |

## What is not verified

- Everything in the browser (C36 and every "same (code)" / "same (SSR)" row): the twin run in `wadesk-playwright-parity` must be done with
  a running reference and a running stack. Nothing has been compared pixel for pixel or flow for flow.
- The migration was applied to a fresh database only (testcontainers and a throwaway container); the backfill of rows that predate the
  new CHECKs (trim, truncate, name filled from the website) is written but not exercised against a database that already has companies.
- The Agent preset's new grants on a running environment appear when the 10-minute permission cache expires.
