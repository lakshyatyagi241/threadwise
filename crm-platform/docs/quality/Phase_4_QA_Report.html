What changed in how this was run. The sandbox had only Chromium. Firefox and WebKit were installed (with their host libraries), and a small stand-in API was written so the public pages render without Postgres and Redis. That is what makes the public run honest: the pages are real, only the backend answers are faked.

The most useful findings were about the tests, not the browsers: two of the first failures came from wrong assumptions in the tests (the OS dark preference does not set the theme; the theme cookie is written after the colour flips), and one came from the environment (a proxy with no API behind it). The one real product defect was an accessibility one that every engine shared.

Nothing here runs on GitHub automatically: the check workflows were removed in #328 and jobs do not start on this account. The new Browsers workflow is manual, like Quality and Security, and has never run. After the accessibility fix the public matrix was not re-run on the three engines, and type-check and lint of the web app were not run in the last session.
