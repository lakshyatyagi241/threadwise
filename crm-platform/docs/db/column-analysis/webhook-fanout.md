## `webhook_forward_failures`

**Purpose:** Dead-letter copy of a forwarded Meta webhook body that exhausted its retries, kept so an operator can replay it.

**Linked to:** api modules/webhook-fanout (processor keepFailure, controller replay, daily retention prune). Threadwise-native.

**Facts:** RLS on+forced · plain · created in `20261014100000_wfwd_webhook_forwarding.sql` · Drizzle `packages/db/src/schema/webhook-fanout/tables.ts`

**Design notes:** Platform table. Stores raw bytea body (may contain customer PII/messages) for a retention window, pruned daily in batches. No updated_at/row_version trigger because rows are almost immutable.
