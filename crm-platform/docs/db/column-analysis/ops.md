## `audit_log`

**Purpose:** Append-only audit trail of who changed which record and how (module, record id, action, field delta), including impersonation stamps.

**Linked to:** api kernel/audit (AuditService), ~27 modules write audit_log (crm, auth, plans-subscriptions-trials, platform-payment-gateways, workspaces-teams-tenancy, marketplace, whatsapp-cloud-api-waba); readers: crm field history, auth security center, admin-console-shell, dashboards-analytics-charts, notifications-activity-audit. Reference activity_log equivalent.

**Facts:** RLS on+forced · partitioned · created in `0006_outbox_audit.sql` · Drizzle `packages/db/src/schema/ops.ts`

**Design notes:** Monthly partitioned (PK id, at). ip exists in the database (0006_outbox_audit.sql) but is missing from Drizzle ops.ts, so Drizzle inserts cannot set it and schema/DB drift. actor_type and module are free text with no CHECK; record_id is NOT NULL so events without a subject need a placeholder id. Trigger trg_audit_log_impersonation adds _impersonatedBy into delta.

## `event_outbox`

**Purpose:** Transactional outbox: domain events written in the same transaction as the business change, drained by a worker that dispatches them with retry/backoff.

**Linked to:** api workers/outbox-drain.service.ts (drain + dispatch), kernel outbox writer, modules/marketplace, crm, platform-infrastructure (health), whatsapp-devices-baileys

**Facts:** RLS on+forced · partitioned · created in `0006_outbox_audit.sql` · Drizzle `packages/db/src/schema/ops.ts`

**Design notes:** Monthly partitioned (PK id, created_at). status is free text (pending\|processing\|done\|dead) with no CHECK and has no index for processing rows stuck after a worker crash (no visibility timeout column). Partial index on (available_at,id) WHERE pending is correct.
