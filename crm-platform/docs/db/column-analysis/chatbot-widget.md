## `chatbot_widget_visitors`

**Purpose:** One anonymous browser visiting a widget: server-minted visitor uuid, optional name/email/phone captured by the intake form, link to the conversation and basic tracking (referrer, UA, IP, first/last seen).

**Linked to:** api modules/chatbot-widget widget-visitors.repository.ts, widget-public.service.ts (config/message/history calls); widgets.repository.ts (visitor counts for list/stat cards); Team Inbox shows visitor name; Reference chatbot_widget_visitors.

**Facts:** RLS on+forced · plain · created in `20261001103300_wgt_threadwise_schema.sql` · Drizzle `packages/db/src/schema/chatbot-widget/tables.ts`

**Design notes:** visitor_uuid is globally unique, so the index (org_id, widget_id, visitor_uuid) is redundant with it and with the unique constraint. visitor_uuid is text (Reference varchar 64) holding a UUIDv4: use uuid type. No retention/purge for IP and user agent (personal data). No visitor list UI in Reference or port.
