## `status_options`

**Purpose:** Configurable choice lists for CRM records: contact statuses and lifecycle stages (and other option groups), with colour, default, won/lost flags and a status-to-stage link.

**Linked to:** crm status-options.service + contacts.repository.ts/segment-rule-context.ts (contact status/lifecycle), growth-pilot, lead-scoring, forms-builder, leads; web features/contacts-attributes-tags (status-stage settings), segments.

**Facts:** RLS on+forced · plain · created in `0010_add_contact_properties.sql` · Drizzle `packages/db/src/schema/field-metadata.ts`
