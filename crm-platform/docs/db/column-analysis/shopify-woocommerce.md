**Linked to:** API shopify-woocommerce (stores.repository, woocommerce.service, webhook-pipeline, import.service), flow-builder-editor builder-context, dashboards-analytics-charts, admin-console-shell overview; web /woocommerce and Settings > Integrations; Reference woocommerce_integrations

**Facts:** RLS on+forced · plain · created in `20261001101800_ecom_threadwise_schema.sql` · Drizzle `packages/db/src/schema/shopify-woocommerce/tables.ts`

**Design notes:** Twin of shopify_integrations but with store_* profile columns and consumer key/secret instead of an OAuth token. status has no CHECK; products/orders/customers_synced_at are always set together by setSynced() so they are redundant (one last_synced_at + sync_stats would do). Two indexes on webhook_secret (plain org-scoped and global unique partial) overlap. metadata jsonb holds webhook_ids that arguably belong in a column/child table. Only the latest row per org is used in UI (latestShopify) though the schema allows many stores.

## `woocommerce_stock_waitlist`

**Purpose:** Customers waiting to be messaged when an out-of-stock WooCommerce product is back in stock (TW-ECOM-020).

**Linked to:** API shopify-woocommerce (stock.repository, stock.service, webhook-pipeline); Reference WooCommerce stock waitlist

**Facts:** RLS on+forced · plain · created in `20261001101800_ecom_threadwise_schema.sql` · Drizzle `packages/db/src/schema/shopify-woocommerce/tables.ts`
