## `api_keys`

**Purpose:** Workspace API keys: `bearer` customer keys (wsk_..., sha256) for the Developer REST API v1, and `signed` partner keys (ApiKey prefix.secret + HMAC) for the public/partner API.

**Linked to:** api modules/developer-rest-api-v1 (key console, bearer guard), public-api (signed guard, lead intake), plans-subscriptions-trials (plan usage count), auth/cli/seed-auth; web features/auth-registration-security (key settings). Reference api_keys (2026_06_13_000100).

**Facts:** RLS on+forced · plain · created in `0005_partner_agents.sql` · Drizzle `packages/db/src/schema/partner.ts`

**Design notes:** Two identity schemes share one table, split by kind with a CHECK on signing_secret_enc. created_by always equals user_id in code (duplicate), and has no FK. expires_at is enforced by guards but no write path sets it.
