## `meta_campaigns`

**Purpose:** One Meta (Facebook/Instagram) ad campaign a workspace built in the Meta Ads builder, including its Click-to-WhatsApp creative, targeting, budget and synced Meta ids/insights.

**Linked to:** Reference MetaAdsController/MetaCampaign + MetaGraphClient (user/meta-ads screens, analytics). No API module, web feature or worker yet: README lists meta-ads 'not started'. Also read by Reference admin/analytics roll-ups.

**Facts:** RLS on+forced · plain · created in `20261001101900_mads_threadwise_schema.sql` · Drizzle `packages/db/src/schema/meta-ads/tables.ts` · **no production reference to any column (dormant table)**

**Design notes:** Zero code in apps/ or packages/contracts. Reference encrypts name, creative_*, ctwa_phone/message, targeting, meta_last_error at rest; here they are plain text. Reference columns ad_type, publisher_platforms, instagram_positions, instagram_user_id are missing from this table. status/type/objective/budget_level have no CHECK. Money mix: daily_budget numeric major units vs bid_amount bigint minor units.
