## `api_library_apis`

**Purpose:** A saved outbound HTTP API call (method, URL with {{variable}} tokens, headers, JSON/form payload, optional JS payload function, response-to-contact-property mapping) that a workspace builds once and reuses from flow nodes.

**Linked to:** api-library (controller, service, runner, repository, mapper), flow-runtime-engine api-library node; web API Library screens; docs/api/api-library.md; NOT a Reference port (owner request)

**Facts:** RLS on+forced · plain · created in `20261112090000_alib_core.sql` · Drizzle `packages/db/src/schema/api-library/tables.ts`

**Design notes:** Whole definition is stored as jsonb arrays (variables, headers, body, mapping_config, response_variables) which keeps it simple but means no relational integrity (e.g. flows referencing an API by name); secret header values are encrypted inside the headers jsonb; function_code is user JavaScript stored as text and run in a sandbox.

## `api_library_logs`

**Purpose:** Append-only log of every API Library run (form test, flow node, future automation) with masked request, status, timing and response snapshot; kept 30 days.

**Linked to:** api-library (logs repository/service, run service, retention sweep), flow-runtime-engine api-library node (writer), web API Library log viewer; NOT a Reference port

**Facts:** RLS on+forced · partitioned · created in `20261112090000_alib_core.sql` · Drizzle `packages/db/src/schema/api-library/tables.ts`

**Design notes:** Partitioned monthly by created_at with no foreign keys (a stream), so api_uuid, user_id, flow_id, contact_uuid dangle after deletes by design (api_name is a snapshot); stores response bodies (PII risk) up to a size cap; user_id is a bigint while contact/api/run ids are uuids (mixed id styles); source 'automation' has no writer yet.
