## `financial_records_archive`

**Purpose:** Tax-law copy of a paid platform order (plan, add-on or wallet top-up) kept after a workspace is erased, stripped of buyer identity. Survives the org because it has no FK to organizations.

**Linked to:** workspaces-teams-tenancy lifecycle erase (copies from orders) and retention purge; no read screen or export.

**Facts:** RLS on+forced · plain · created in `20261116090000_org_lifecycle.sql` · Drizzle `packages/db/src/schema/foundation.ts`

**Design notes:** Write-only from the app: only retain_until is ever read (purge). Money columns copy orders (numeric, mixed scales 12,2 vs 12,4) instead of repo-standard minor bigint. order_uuid is not unique-indexed. No org_id column: RLS is privileged-only.

**Linked to:** workspaces-teams-tenancy lifecycle service/repository; web workspaces-hub lifecycle history; reminder dedupe.

**Facts:** RLS on+forced · plain · created in `20261116090000_org_lifecycle.sql` · Drizzle `packages/db/src/schema/foundation.ts`

**Design notes:** event_type and actor_type are free text with no CHECK (only stage is checked). Two event vocabularies exist: log rows (reminder_sent, archived, deleted, delete_blocked) vs outbox events (org.archived...). org_id has no FK (intentional) so RLS tenant filter works only while the org id is never reused (identity ids are not reused).
