# Wiring map: Google account (TW-GACC)

Reference: `GoogleAccountController` (`/google-account`), `GoogleCalendarOAuthController` (start, callback, disconnect), `GoogleCalendarService` (OAuth, `DEFAULT_SCOPES`),
`GoogleApiService` (Sheets, Docs, Drive, Forms), `GoogleFlowNodeController` (node endpoints, pickers, Apps Script), `resources/views/user/google-account/index.blade.php`. The
inventory lists the page's consumers inside TW-FLB-055 to 059, TW-FLR-044 to 047 and TW-TIB1-022 but never as a feature of its own: this file is that record (new ids
`TW-GACC-*`, plan in [google-workspace-build.md](../plan/google-workspace-build.md)).

| What             | Where                                                                                                                                                                                                                                                                                                                                                                               |

## Reference behaviour, every consumer

| Consumer in Reference                                                                                       | Here                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/google-account` page: status, four stat cards, scopes granted, account, calendar, Connect and Disconnect  | `google-account-screen.tsx`: status, four stat cards (status, calendars, permissions, last used), account and calendar, the capability list, Connect, Add permissions, Reconnect, Disconnect |
| Missing-scope banner "Reconnect to unlock new flow nodes"                                                   | each capability shows Allowed or a tick box; "Add permissions" asks Google for only the ticked ones and keeps the rest                                                                       |
| Admin-setup banner when the platform client is not set                                                      | status `unavailable`: "Google is not set up for this platform" with the Connect button not offered                                                                                           |
| Connect and Disconnect on `/appointments/oauth/google/*`; the page the button was clicked on is returned to | `POST /google-account/connect { returnTo }` (a path inside the app, validated), signed state; callback redirects to `returnTo?calendar=<outcome>`; same-origin only                          |
| Disconnect revokes at Google first, carries on if Google fails                                              | same                                                                                                                                                                                         |
| Calendar and Meet use the same token (`BookAppointment`, `GoogleMeet` nodes)                                | `APPOINTMENT_CALENDAR` and `GOOGLE_WORKSPACE` over the one grant                                                                                                                             |
| Sheets write and read nodes, header matching                                                                | `HttpGoogleWorkspace.appendSheetRow`, `readSheetRows` (TW-FLR-044); `placeUnderHeaders`                                                                                                      |
| Docs node: copy, fill `{{k}}` and `{k}`, share                                                              | `generateDoc` (TW-FLR-045); both needle styles restored                                                                                                                                      |
| Forms node and Apps Script webhook                                                                          | `formResponderUrl` (TW-FLR-046) and the existing `google-form-webhook` (token per workspace)                                                                                                 |
| Pickers `GET /api/google/picker/{kind}` (also reports `integration.connected` and `missing`)                | `GET /flows/builder-context/google/:kind` and `/status` (`{ status, granted }`); the inspector notice reads the status                                                                       |
| Apps Script for a form `GET /google-account/forms/{id}/apps-script.gs`                                      | `GET /flows/builder-context/google/forms/:formId/apps-script` (TW-FLB-059, already built)                                                                                                    |
| Master toggle `google_calendar_enabled` gates Sheets, Docs, Forms, Meet and the pickers                     | `GoogleCalendarConfig.credentials()` is checked first by every token request; pickers answer 503 `FLB_INTEGRATION_DISABLED`                                                                  |
| Inbox composer "Send Meet link" (`team-inbox/api/google-meet`)                                              | **Not built**: neither the endpoint nor the button exists (TW-TIB1-022); `createMeet` is ready for it                                                                                        |
| Plan feature `integration_google_calendar` on the callback and `google-account` plan gate                   | not ported (no key in the plan registry); recorded as `intended` in the parity file                                                                                                          |

## Not built, recorded

- TW-TIB1-022 the inbox Meet composer; TW-FLR-081 the Google Sheet row trigger (needs a polling or push feed).
- Real-time calendar read-back (watch channels, sync tokens): not built; the hourly drift reconcile replaces it (TW-GACC-011, owner decision). A watch channel would only make it faster (plan, open decision 11).
