# Wiring map: ai-agents-training (AIAG), AI Training slice

Read with [the inventory entry](../inventory/ai-agents-training.md) and [the API doc](../../api/ai-agents-training.md). `built` = in this repo and tested; `intended` =
deliberately different (reason in [parity/ai-agents-training.md](../parity/ai-agents-training.md)); `blocked:<what>` = not in this slice; `owned:<domain>` = another domain's.
