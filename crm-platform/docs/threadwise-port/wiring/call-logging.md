# Wiring map: call logging (CLG, the calls that are not WhatsApp calls)

Not a Reference feature: Reference logged only WhatsApp calls (`wa_calls`, mirrored to `ai_call_logs`). Requested by the owner so that every call is logged the
same way and shows up on the contact timeline and the Call logs screen. Lives in the CALL domain (`modules/calling-voice/logging`, `infra/providers/telephony`).
Read with [specs/call-logging.md](../../specs/call-logging.md) and [api/call-logging.md](../../api/call-logging.md). New ids: `WIRE-CLG-*`.

## How a call gets in

| Door                  | Trigger                                          | Auth                                                | Writer                                                                                                                          | Source                           |
| --------------------- | ------------------------------------------------ | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| Log a call            | `POST /v2/calls/log`                             | session, `call.logs.create`                         | `CallLogEntriesService.log` -> `write`                                                                                          | `manual`, `web_click_to_call`    |
| The mobile app        | `POST /v2/calls/ingest`                          | the person's app token, `call.logs.create`          | `CallIngestService.ingest` -> `write` (savepoint per entry)                                                                     | `mobile_app`                     |
| A provider's callback | `POST /v2/public/webhooks/telephony/:connection` | signature over the raw body, replay window          | `TelephonyWebhookService` (verify, enqueue) -> `TelephonyIngestProcessor` (worker) -> `TelephonyEventsService.apply` -> `write` | `telephony`, `web_click_to_call` |
| Click-to-call         | `POST /v2/calls/click-to-call`                   | session, `call.logs.create`; ConsentGate on `voice` | `ClickToCallService.place` (gate, provider, placement) then the callback above                                                  | `web_click_to_call`              |

## Where it plugs into the rest

| Seam                  | What                                                                                                                                                                                         | Where                                                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Contact timeline      | one `contact_activities` line per call (`call_<source>`, "Outbound call, Connected, 4 min, by Priya", notes preview), rewritten on edit, removed on delete; `last_activity_at` moved         | `CallLogEntriesService.write`; `ContactActivitiesRepository.insert / rewrite / remove` (rewrite and remove are new, used only here) |
| Contact match         | `contact_identities` then `contacts.normalized_phone`, the canonical phone (`canonicalizeLocalPhone` + the workspace default country), among the contacts the person may read                | `CallLogEntriesRepository.contactByPhone`, `contactFor`                                                                             |
| Contact creation      | `ContactsService.resolveOrCreateByIdentity` (plan contact cap, default stage and status, `contact.created`), only when `create_contacts_from_unknown_callers` is on                          | `CallIngestService`, `TelephonyEventsService`                                                                                       |
| Tasks                 | `TasksService.createIn(tx, ...)` (new: `create` inside the caller's transaction); the follow-up is linked back in `follow_up_task_id`                                                        | `CallLogEntriesService.log`                                                                                                         |
| Call logs / analytics | `CallLogsRepository` reads `wa_calls` and `call_log_entries` as one set (`UNIFIED`); `source` filter, `bySource`; WhatsApp-only paths (`byUuid`, ledger, playback) read `wa_calls` as before | `calling-voice/call-logs.repository.ts`, `call-logs.service.ts`                                                                     |
| ConsentGate           | `voice` channel, `service_messaging` or `marketing_messaging` before a call is placed (DNC = `on_dnc_list`); `call_recording` purpose before a recording reference is kept                   | `ClickToCallService`, `TelephonyEventsService`; guard primitive `clickToCall` in `consent-gate.allowlist.ts`                        |
| Recording rules       | `call_recording_settings` (switch, mode, retention, notice version) read through `CallRecordingSettingsService.read`; reference swept by the same retention window                           | `TelephonyEventsService.recordingOf`, `CallLogRetentionService`                                                                     |
| Permissions           | `call.logs.create`, `call.logging.manage` (new); `call.logs.read` (existing; Agent added at `own`)                                                                                           | migration `20261227090100_call_logging_permissions`                                                                                 |
| Privacy / erasure     | `call_log_entries` in the `calls.logs` holder: number, notes, external id and recording reference are cleared                                                                                | `privacy/manifests/calls.ts`                                                                                                        |
| Provider port         | `TelephonyProvider`, `TelephonyProviderRegistry` (`generic`; `fake` outside production); the registry is global through `ProvidersModule`                                                    | `infra/providers/telephony/`                                                                                                        |
| Queue                 | `QUEUES.TELEPHONY_INGEST` (`telephony-ingest`), processor in `CallingVoiceWorkerModule`                                                                                                      | `infra/queue/queues.ts`                                                                                                             |
| Worker jobs           | daily `CallLogRetentionService` (03:41): clears recording references past the window, forgets click-to-call placements older than 2 days                                                     | `calling-voice-worker.module.ts`                                                                                                    |
| Audit and events      | modules `call_log_entries`, `call_logging_settings`, `telephony_connections`, `telephony_click_calls`; events in [api/call-logging.md](../../api/call-logging.md)                            | each service, same transaction as the write                                                                                         |
