# Call the API from the app

Same conventions as the web (`frontend-api-call` skill), different plumbing: there is no cookie proxy; `apiFetch` (`src/lib/api/client.ts`) attaches the bearer token, rotates it, sends `X-Request-Id` and the `X-App-*` headers,
times out after 30 s, turns problem+json into `ApiError`, and parses the answer. Design: ADR-0023, ADR-0024.

## The shape of a feature's data code

```ts
// src/features/contacts/api.ts: one function per endpoint, types from the contract (names here are real: crm/contact.ts)
import {
  contactResponseSchema,
  pageResponseSchema,
  type CreateContactInput,
  type ListContactsQuery,
} from '@crm/contracts';
import { apiFetch } from '@/lib/api';

const contactPageSchema = pageResponseSchema(contactResponseSchema); // { data: Contact[], page: { nextCursor, hasMore, limit } }

export const listContacts = (query: ListContactsQuery, signal?: AbortSignal) =>
  apiFetch('/v2/contacts', { query, schema: contactPageSchema, signal });

export const createContact = (body: CreateContactInput, idempotencyKey: string) =>
  apiFetch('/v2/contacts', { method: 'POST', body, schema: contactResponseSchema, idempotencyKey });
```

Check the real route and schema names in the API controller and `packages/contracts/src/<area>/` first (do not guess a path; the web's `apps/web/src/features/<area>` shows the call). If the schema does not exist, invoke `contracts-change` (and the API skills).

```ts
// src/features/contacts/use-contacts.ts
export const contactsKey = (filters: ContactFilters) => ['contacts', filters] as const;

export function useContacts(filters: ContactFilters) {
  return useInfiniteQuery({
    queryKey: contactsKey(filters),
    queryFn: ({ pageParam, signal }) =>
      listContacts({ ...filters, limit: 50, cursor: pageParam }, signal),
    initialPageParam: undefined as string | undefined,
    getNextPageParam: (last) => (last.page.hasMore ? last.page.nextCursor : undefined),
  });
}

import * as Crypto from 'expo-crypto';

export function useCreateContact() {
  const queryClient = useQueryClient();
  const key = useRef(Crypto.randomUUID()); // one key per user action; a retry of the same submit reuses it
  return useMutation({
    mutationFn: (body: CreateContactInput) => createContact(body, key.current),
    onSuccess: () => {
      key.current = Crypto.randomUUID();
      void queryClient.invalidateQueries({ queryKey: ['contacts'] });
    },
  });
}
```

## Rules

- **Types come from `@crm/contracts`.** If you are typing a response by hand, stop. Parse every response with its schema (the `schema` option); a mismatch becomes `CLIENT_CONTRACT_MISMATCH`.
- **Errors by code.** `if (isApiError(e) && e.code === ERROR_CODES.X)`. Never compare `e.message`. Unknown codes fall back to `messageForError(e, t)`. A screen's own codes map to its own `t()` keys (see `features/auth/use-sign-in.ts`).
  `e.isConnectivity` means offline/timeout (offer retry), `e.status === 429` + `e.retryAfterSeconds` (say when), `e.isRowVersionConflict` (reload and re-apply), `e.isIdleTimeout` (the session ended; the next call signs the person out).
- **Pagination is a cursor** (`limit`, `cursor`, `page.nextCursor`, `page.hasMore`). There is no total and no page number.
- **Mutations** carry an `Idempotency-Key` (generated by `apiFetch` if you pass none). To make a user-initiated retry safe, create the key once per user action (above) and reuse it on retry. Updates send `rowVersion`.
- **Money is a string** from the API until a decimal library touches it; never `parseFloat` an amount. Ids are uuids; internal ids never appear.
- **Public doors** (sign-in, MFA, workspace pick, logout) pass `auth: false`. Everything else is authenticated by default.
- **Cancellation:** pass the `signal` TanStack Query gives you. A screen that unmounts cancels its requests.
- **Never** call `fetch` yourself (lint error), put a token in a query string, log a request or response body, store server data in React state or a store (the query cache is the only copy), or retry a mutation automatically.
- **Query keys** start with the resource: `['contacts', filters]`, `['contacts', id]`. Invalidate by prefix after a mutation. Sign-out clears everything.
- **Realtime** (Socket.IO) arrives with the inbox; update the query cache from socket events with `queryClient.setQueryData`, do not keep a second copy.
